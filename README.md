# 自习室设计工作台

实景校正版：大厅实测净2.8×8.8m；当前发布方案为20席紧凑试排（大厅18席、小厅2席）。封原大厅—小厅宽门洞，保留大厅—服务区门，前台玻璃门作为日常入口。支持平面/三维编辑、桌椅联动、尺寸标注、采购预算和装修任务。

从协作邀请链接进入同一房间后，布局、备注、采购及任务约每3秒通过Supabase同步。不同字段自动合并，同一处同时修改会提示选择。断网草稿在本机暂存，联网后重试；请确认“已同步到云端”再关页。邀请链接含编辑权限，只发给协作人。

直接打开普通网址或下载HTML可本机编辑；本机模式不会上传。JSON用于备份，HTML用于独立副本。网页仅包含公开连接配置，不含房间口令或管理员密钥。GitHub Pages和Supabase均不依赖你的电脑开机；免费服务的可用性与暂停规则以平台为准。

除大厅净尺寸外，其余区域、墙厚、窗位和门洞尺寸待现场复测。编辑器采用墙中心线，暂用12cm墙厚补偿后大厅墙线为2.92×8.92m；墙线面积不代表实测净面积或建筑面积。桌位数量不代表容量已通过合规核验；采购单价保留用户原数值，新增封门项目尚未报价。日常单入口与取消原门疏散功能是不同事项，需现场复核后确定施工方式。
