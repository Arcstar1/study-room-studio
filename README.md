# 自习室设计工作台

实景校正版：大厅实测净2.8×8.8m；当前发布方案为20席条件试排（大厅18席、小厅2席），按用户商品图采用外宽83.2×深60cm、隔板总高120cm的自习桌，桌面高75cm仍待确认。封原大厅—小厅宽门洞，保留大厅—服务区门，前台玻璃门作为日常入口。支持平面/三维编辑、桌椅联动、尺寸标注、采购预算和装修任务。

20席版本假设椅子前缘收进桌下10cm，此时模型椅背间约90cm；两侧各后拉25cm只余约40cm。新增“平面拉椅25cm”只显示预览占位，不修改共享家具位置。真实坐姿、扶手、暖气和门洞尺寸需要样品及现场验证，不能凭模型宣布20席可正常运营。桌面高度与隔板总高可分别编辑。商品截图124.2元/张仅作预算占位，不含尚未确认的运费、安装和椅子。

从协作邀请链接进入同一房间后，布局、备注、采购及任务约每3秒通过Supabase同步。不同字段自动合并，同一处同时修改会提示选择。断网草稿在本机暂存，联网后重试；请确认“已同步到云端”再关页。邀请链接含编辑权限，只发给协作人。

顶部“方案库 / 另存为”支持原方案之外最多30份独立云端方案。先“另存为新方案并打开”，再尝试新布局；每份方案有独立的修订记录、待同步草稿和邀请链接。“复制本方案链接”会让协作人进入当前这一份。切换前先保存当前修改，断网或有冲突时停止切换；加载目标失败也保留当前方案。旧邀请链接继续打开原方案。装修任务页的“本机备份”只保存在当前浏览器，最近8份，与云端方案库分开。

本次保留原20席商品桌方案，另存一份保留副本和“20席少改动优化版 · 保留地砖与两位餐吧”。优化版保留20席，常用餐凳减为2把，桶装饮水机有条件移位；整铺地砖暂不采购，补充现有饰面检查、实摆试坐及报价口径核对任务。采购单价未擅改，预算占位减少不等于已确认净节省。保存的副本也可继续编辑，长期归档可下载JSON。
